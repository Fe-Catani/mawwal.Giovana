# Site — Captação de Consultores

Landing page moderna, organizada e responsiva para captar novos consultores.

- Apresentação da oportunidade
- Destaque para o Kit Inicial
- Benefícios para consultores
- Explicação de como começar
- Formulário de interesse
- Botões de contato pelo WhatsApp
- Layout responsivo para celular e computador
- Espaços preparados para logotipo e imagens oficiais
