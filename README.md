## 📋 Sobre o projeto

Landing page responsiva para captação de novos consultores(as), apresentando a oportunidade, o kit inicial e os benefícios de se tornar um(a) revendedor(a).

## 🚀 Funcionalidades

- ✅ Apresentação da oportunidade
- ✅ Destaque para o Kit Inicial
- ✅ Benefícios para consultores
- ✅ Explicação de como começar
- ✅ Formulário de interesse com validação (JavaScript)
- ✅ Envio de dados do formulário via WhatsApp
- ✅ Botão flutuante de contato pelo WhatsApp
- ✅ Layout responsivo para celular e computador
- ✅ Espaços preparados para logotipo e imagens oficiais

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (validação de formulário, integração com WhatsApp)

## 📁 Estrutura do projeto

```
├── index.html   # Página principal
├── css/         # Estilos
├── js/          # Validação do formulário e envio via WhatsApp
└── assets/      # Imagens e recursos estáticos
```

## ⚙️ Instalação e execução

Projeto estático, sem dependências ou build. Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor de arquivos estáticos (ex: `npx serve`, GitHub Pages, etc.).
