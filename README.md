# Site - Captação de Consultores

Esqueleto do site para captação de novos consultores. Inclui HTML, CSS e JS básicos, com placeholders para imagens, logo e telefone de contato.

Como testar localmente:

1. Abra a pasta do projeto no terminal:

```bash
cd /Users/catanu/Giovana
```

2. Abra o arquivo `index.html` em um navegador (duplo clique ou via Live Server).

O que precisa ser atualizado:

- Substituir o logotipo e imagens em `index.html`/`css`.
- Atualizar o número de WhatsApp em `js/main.js` (variável `phone`).
- Conferir e ajustar textos e valores conforme materiais oficiais.
- Implementar envio de formulário para um servidor/back-end se necessário.

Próximos passos sugeridos:

- Inserir assets (logo, fotos do kit) na pasta `assets/`.
- Ajustar identidade visual (cores) no `css/styles.css` conforme materiais.
- Integrar com uma solução de captura (Google Sheets, Zapier, backend ou CRM).
